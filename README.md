# Almond65

Almond65 is a free and open-source emulator for the Nintendo 64 and Nintendo 64 Disk Drive written in C++ currently for Windows. It is a fork of Project64 focused on removing intrusive donation screens and improving user experience.

## Features

- Development and debugging tools  
- Save/load states  
- Fullscreen support  
- Controller support  
- Support for many popular N64 emulator plugins

## Installation

Download the latest builds and releases from the repository’s releases page.

## Supported requirements

- Operating system: Windows 10 and 11 (64-bit)  
- CPU: 1GHz or faster Intel or AMD processor with at least SSE2 support  
- RAM: 2GB or more  
- Graphics card: DirectX 8, OpenGL 3.3, or Vulkan 1.1 capable  

*Note: Intel integrated graphics may have issues even if requirements are met.*
